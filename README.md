
 🏨 SmartStay AI – Hotel Management System

SmartStay AI is a web-based hotel management system designed to make hotel operations easier, smarter, and more efficient. It provides a user-friendly platform for managing hotel rooms, bookings, guest requests, and hotel services with AI-powered assistance.

 🌐 Live Demo

https://smartstay-ai-hotel-management-system.onrender.com

 ✨ Features

- 🏨 Room Management
- 📅 Room Booking System
- 🤖 AI Chatbot Assistant
- 🌐 Hindi and English Language Support
- 🍽️ Food Service Requests
- 🧳 Luggage Assistance
- 🔧 Maintenance Service Requests
- 👤 Guest Management
- 📋 Booking Management
- 🔐 Admin Dashboard
- 📊 Room and Booking Statistics
- 📱 Responsive and User-Friendly Interface

 🛠️ Technologies Used

 Frontend
- HTML5 – Website Structure
- CSS3 – Styling and Layout
- JavaScript – Interactive Features

 Backend
- Python – Backend Programming
- Flask – Web Framework
- SQLite – Database Management

📌 Project Modules
 1. User Module
Allows users to explore rooms and interact with hotel services.
 2. Room Management
Displays available rooms and their details.
 3. Booking Module
Helps users manage their room booking requests.
 4. AI Assistant
Provides chatbot assistance in Hindi and English.
5. Hotel Services
Allows guests to submit requests for food, luggage assistance, and maintenance.
 6. Admin Panel
Allows administrators to manage rooms, bookings, and guest requests.

 🎯 Project Objectives
- To simplify hotel management operations.
- To improve guest experience.
- To provide quick access to hotel services.
- To reduce manual work through automation.
- To integrate AI assistance into hotel management.
